# Interactive Demo Site

## The problem

Code samples and long READMEs are useful — but some viewers just want to **click through** Photo Log or Intelligent QI without installing anything.

**What this folder does:** a static HTML/CSS/JS demo page (no backend) with wizard-style demos and project map cards.

## Who it helps

- External viewers / interviewers who want a browser demo  
- Anyone on a machine where installing Python/Node is awkward  
- Portfolio readers starting from the [automation](https://github.com/seancmry/automation) repo  

## How to run

No build step. From this folder:

1. Open `index.html` in a browser (double-click, or “Open with Live Server” in your editor).  
2. Try the Photo Log and Intelligent QI demos.  
3. Use the project map cards for Supplier Risk Radar, OTIF Root Cause Lab, and MTO Traceability Map.  

Portfolio-safe: no live ERP, no secrets, no customer data.
