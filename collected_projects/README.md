# Collected projects

## The problem

Useful automation work often sits inside a private ERP or ops stack. Sharing the *idea* without leaking customers, tokens, or internal URLs is hard.

**What this folder does:** it holds portfolio-style folders for selected automation workstreams and AI demos — each with a plain README, a walkthrough page, and sanitised samples where useful.

## Who it helps

- People browsing the [automation](https://github.com/seancmry/automation) repo  
- Stakeholders who want “what does this do?” before diving into code  
- Learners who prefer a short problem → who → run path  

## How to run / browse

1. Open a project’s `README.md` (problem, who it helps, how to run or browse).  
2. Open `demo_page.md` for a longer, webpage-style walkthrough.  
3. Open `sample_*.py` (when present) for curated implementation snippets.  

**Fully runnable:** [hr_ai_hitl](./hr_ai_hitl/) — follow its README.  
**Static demos in a browser:** [site](./site/) — open the HTML there.  
**Other projects:** read + samples (not full installable products).
